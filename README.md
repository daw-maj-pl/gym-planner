## Gym Planner

AI system capable of generating fully customizable workout plans based on each user's goals, preferences, and constraints.

## Project Specifications

- AI integration into full stack application
- Neon authentication

### Technologies

- React
- TypeScript
- React Router
- TailwindCSS
- Lucide
- RWD
- Node.js
- Express
- Prisma
- Neon
- PostgreSQL
- OpenAI
- OpenRouter
- Vite
